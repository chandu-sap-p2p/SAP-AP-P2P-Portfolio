# SAP Accounts Payable (P2P) Portfolio

Welcome to my professional portfolio focused on SAP Accounts Payable and Procure-to-Pay (P2P) operations.

This repository showcases practical examples, process documentation, and reporting concepts relevant to SAP S/4HANA Accounts Payable.

## About This Portfolio

I focus on vendor invoice processing, invoice verification, discrepancy resolution, vendor reconciliation, and Accounts Payable reporting.

## Key Areas

- PO-Based and Non-PO Invoice Processing
- Two-Way and Three-Way Invoice Matching
- Goods Receipt / Invoice Receipt (GR/IR) Clearing
- Blocked Invoice Investigation
- Vendor Statement Reconciliation
- Invoice Ageing and Payment Due-Date Monitoring
- Month-End Accounts Payable Support
- Advanced Excel Reporting and Dashboard Analysis

## Projects

### 1. AP Invoice Tracking and Ageing Dashboard
An Excel-based project to monitor invoice status, outstanding balances, overdue invoices, and ageing categories using fictional data.

### 2. SAP S/4HANA P2P Process Guide
Documentation covering the Procure-to-Pay lifecycle, relevant SAP transactions, and common Accounts Payable scenarios.

### 3. Vendor Reconciliation and GR/IR Analysis
Sample reconciliation exercises demonstrating how outstanding items and invoice discrepancies can be investigated.

### 4. AP Invoice Exception Analysis
Fictional case studies covering duplicate invoice checks, price and quantity variances, missing goods receipts, and blocked invoices.

## Tools and Skills

- SAP S/4HANA Accounts Payable / P2P
- SAP GUI
- Microsoft Excel
- PivotTables, lookup formulas, conditional formatting, and charts
