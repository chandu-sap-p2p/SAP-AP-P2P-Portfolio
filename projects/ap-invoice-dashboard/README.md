# AP Invoice Tracking and Ageing Dashboard

## Project Overview
This project demonstrates Accounts Payable invoice monitoring and ageing analysis using Microsoft Excel and fictional invoice data.

## Objectives
- Track PO-based and Non-PO vendor invoices.
- Monitor invoice status: Open, Blocked, Paid, and Parked.
- Identify overdue invoices using ageing buckets.
- Review vendor-wise outstanding balances.
- Support AP reporting and invoice exception follow-up.

## Workbook Contents
- **Dashboard:** KPI summaries, invoice status analysis, ageing summaries, and charts.
- **Invoice Tracker:** Invoice IDs, vendor details, invoice types, PO/GR references, dates, amounts, statuses, and ageing formulas.
- **Read Me:** Workbook purpose and usage instructions.

## Tools Used
- Microsoft Excel
- Excel formulas
- Data filtering and conditional formatting
- Dashboard charts

## Business Relevance
The workbook illustrates how an Accounts Payable team can monitor invoice queues, identify overdue items, review blocked invoices, and prioritize follow-up activities.

## Data Disclaimer
All invoice records and vendor names are fictional and created for demonstration purposes. This workbook is not connected to a live SAP system and does not contain actual company data.
